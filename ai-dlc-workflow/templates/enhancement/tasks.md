# Tasks — <change-name>

Ordered, small implementation tasks, each tagged to a requirement from `requirements.md`.

- [ ] T1 — [task] (Req: #)
- [ ] T2 — [task] (Req: #)
- [ ] T3 — [task] (Req: #)

If `/specs/baseline/test-coverage.md` marks the affected area as untested, add a characterization-test
task capturing current behavior, placed immediately before the task that changes that area — same rule
as the spec-first workflow.

Implementation proceeds one task (or small task group) at a time; each shows a diff and waits for
approval before the next starts.
